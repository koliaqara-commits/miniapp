# Kasper Mini App

Статический прототип Telegram Mini App для сделок, балансов, транзакций и профиля.

## Локальный запуск

Можно открыть `index.html` в браузере. Для проверки через Telegram Mini App понадобится HTTPS-хостинг.

## Файлы

- `index.html` — разметка экранов
- `style.css` — мобильный дизайн
- `app.js` — демо-логика и Telegram WebApp init
